# GameDB-32X
Sega 32X, part of [GameDB](https://github.com/niemasd/GameDB).

## Structured Downloads
* **[`32X.data.json`](https://github.com/niemasd/GameDB-32X/releases/latest/download/32X.data.json):** All data, structured in the JSON format
* **[`32X.data.tsv`](https://github.com/niemasd/GameDB-32X/releases/latest/download/32X.data.tsv):** All data, structured in the TSV format
* **[`32X.release_dates.pdf`](https://github.com/niemasd/GameDB-32X/releases/latest/download/32X.release_dates.pdf):** Histogram of release dates, stratified by region
* **[`32X.titles.json`](https://github.com/niemasd/GameDB-32X/releases/latest/download/32X.titles.json):** Mapping of serial numbers to game titles, structured in the JSON format

# Notes

## Uniquely Identifying Games

For now, I am just using the CRC32 hash of each game to uniquely identify it. In the future, more sophisticated approaches can be discovered.
